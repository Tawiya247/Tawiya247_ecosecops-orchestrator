Mathematical & Algorithmic SpecificationsA. Software Carbon Intensity ($SCI$) FormulaYou must implement the standard $SCI$ metric defined by ISO/IEC 21031:2024 in core/metrics.py:$$SCI = \frac{(E \cdot I) + M}{R}$$$E$: Operational energy consumption in $kWh$ (derived from CPU/GPU execution time and utilization).$I$: Grid carbon intensity in $gCO_2e/kWh$ retrieved live via ElectricityMaps API.$M$: Embodied carbon of hardware amortized over execution time.$R$: Functional unit (e.g., per API request, per CI build run).B. Security-Carbon Priority Score ($SPSC$)To prioritize remediation tasks, calculate $SPSC$ in core/metrics.py:$$SPSC = \alpha \cdot \text{CVSS} + \beta \cdot \left( \frac{I_{\text{actuel}}}{I_{\text{référence}}} \right) + \gamma \cdot U_{\text{CPU}}$$Where $\text{CVSS}$ is the vulnerability score from OSV, $I_{\text{actuel}}$ is live grid carbon intensity, $U_{\text{CPU}}$ is average processor load, and $\alpha=0.5, \beta=0.3, \gamma=0.2$.   4.
